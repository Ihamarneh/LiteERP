# Integration examples

These snippets demonstrate that LiteERP markup can be generated by different
rendering technologies. Paths should be adapted to the host application.

## Thymeleaf

```html
<link rel="stylesheet" th:href="@{/assets/liteerp/liteerp.css}">

<a th:each="item : ${menuItems}"
   th:href="@{${item.url}}"
   th:text="${item.label}"
   class="lerp-nav-link">Menu item</a>

<script type="module" th:src="@{/assets/liteerp/liteerp.js}"></script>
```

## JSP / JSTL

```jsp
<link rel="stylesheet" href="${pageContext.request.contextPath}/assets/liteerp/liteerp.css">

<c:forEach items="${menuItems}" var="item">
  <a class="lerp-nav-link" href="<c:url value='${item.url}'/>">
    <c:out value="${item.label}" />
  </a>
</c:forEach>
```

## JSF

```xhtml
<h:outputStylesheet library="liteerp" name="liteerp.css" />

<ui:repeat value="#{navigationBean.items}" var="item">
  <h:link styleClass="lerp-nav-link" outcome="#{item.outcome}">
    <h:outputText value="#{item.label}" />
  </h:link>
</ui:repeat>

<h:outputScript library="liteerp" name="liteerp.js" target="body" />
```

## React

```jsx
import 'liteerp/css';
import 'liteerp';

export function MetricCard({ label, value, change }) {
  return (
    <article className="lerp-card lerp-metric">
      <span className="lerp-metric-label">{label}</span>
      <strong className="lerp-metric-value">{value}</strong>
      <span className="lerp-trend lerp-trend-up">{change}</span>
    </article>
  );
}
```

React applications may manage the sidebar and theme with React state instead
of loading LiteERP's optional JavaScript.

## Angular

Add the stylesheet to `angular.json`, then use LiteERP classes in a component:

```html
<article class="lerp-card lerp-metric" *ngFor="let metric of metrics">
  <span class="lerp-metric-label">{{ metric.label }}</span>
  <strong class="lerp-metric-value">{{ metric.value }}</strong>
</article>
```

Angular applications can implement behavior with directives while retaining
the same CSS API.
