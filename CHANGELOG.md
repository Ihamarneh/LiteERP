# Changelog

All notable LiteERP changes will be documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Theme-coherent calendar component for standard date inputs.
- Searchable combobox enhancement for standard single-select controls.
- Components catalog page.
- GitHub-ready contribution, conduct, security, and issue metadata.

## [0.1.0] - 2026-11-11

### Added

- Responsive ERP application shell with light and dark themes.
- Sales, purchasing, inventory, finance, HR, administration, and workspace
  template groups.
- Domain-specific create, edit, detail, list, and import flows.
- Client-side demonstrations for search, filtering, CSV export, tabs,
  approvals, notifications, and form feedback.
- Framework-neutral integration guidance and MIT license.
